# فاز سه — نمایشگر سه‌بعدی وب

## هدف
نمایش صحنه در مرورگر با تجربه قابل استفاده روی موبایل و دسکتاپ.

## انتخاب فناوری

گزینه اول برای POC: PlayCanvas و SuperSplat Viewer. پیش از تثبیت، موارد زیر با نسخه واقعی آزمایش شوند:
- امکان embed یا استفاده به‌عنوان component
- کنترل دوربین و محدودیت حرکت
- سازگاری فایل خروجی pipeline
- بارگذاری تدریجی و LOD
- موبایل iOS Safari و Android Chrome
- امکان افزودن overlay میزها
- مجوز و شرایط استفاده تجاری

اگر Viewer آماده نیازهای محصول را پوشش نداد، یک viewer اختصاصی با موتور WebGL/WebGPU مناسب بررسی شود؛ این تصمیم بدون POC گرفته نشود.

## تجربه مشتری

- تصویر preview سریع قبل از بارگذاری صحنه
- دکمه ورود به فضای سه‌بعدی
- کنترل لمسی: drag برای نگاه‌کردن، joystick یا کنترل ساده برای حرکت
- کنترل دسکتاپ: WASD/جهت‌ها و mouse look
- دکمه بازگشت و خروج واضح
- نمایش راهنمای کوتاه در اولین ورود
- امکان خروج به نمای دوبعدی در هر زمان

## کنترل دوربین و حرکت

- محدودیت سرعت و شتاب دوربین
- جلوگیری از عبور از collision mesh در حالت walk
- محدودیت ارتفاع دوربین
- جلوگیری از ورود به نواحی غیرقابل دسترس
- نقطه شروع امن در ورودی یا نقطه تأییدشده
- حالت مشاهده آزاد فقط در صورت پشتیبانی و با برچسب مشخص

توجه: Splat به‌تنهایی collision دقیق ارائه نمی‌دهد. collision mesh باید مستقل و قابل تست باشد. اگر mesh آماده نیست، حالت walk محدود یا حالت مشاهده از نقاط ثابت ارائه شود.

## عملکرد

- lazy load
- LOD و نسخه کم‌حجم برای موبایل
- سقف حجم و تعداد splat متناسب با دستگاه
- pause/cleanup هنگام خروج از viewer
- مدیریت context loss
- fallback برای دستگاه ضعیف یا مرورگر ناسازگار
- اندازه‌گیری زمان first render و frame rate

## اتصال overlay

Viewer باید یک لایه جدا برای نقاط تعاملی داشته باشد. مختصات میزها در coordinate system صحنه تبدیل و روی موقعیت صحیح قرار گیرند. اطلاعات وضعیت میز از API دریافت شود، نه از فایل صحنه.

## تست‌ها

- iPhone Safari
- Android Chrome
- دسکتاپ با GPU قوی و ضعیف
- اینترنت کند و قطع‌شونده
- scene بزرگ
- خروج و ورود مجدد
- چرخش صفحه
- بازگشت به صفحه کافه
- fallback دوبعدی

## معیار پذیرش

صحنه روی دستگاه‌های هدف بارگذاری شود، کنترل‌ها قابل فهم باشند، viewer باعث کندی سایر بخش‌های صفحه نشود و در شرایط ناسازگار fallback مناسب نمایش داده شود.
